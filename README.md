# Doodle - Collaborative Canvas

Real-time collaborative drawing canvas application.

## Features

- 🎨 **Drawing Tools**: Brush, eraser, shapes, text
- 🔄 **Real-time Sync**: See others draw live
- 👥 **User Indicators**: Cursor positions and user colors
- ↩️ **Global Undo/Redo**: Shared history across all users
- 💾 **Persistence**: Auto-save and restore canvas state
- 🔐 **Room System**: Create/join private or public rooms

## Tech Stack

- **Frontend**: React + TypeScript + Vite + Tailwind CSS + Zustand
- **Backend**: Node.js + Express + Socket.io + MongoDB

## Quick Start

### Prerequisites

- Node.js 18+
- MongoDB Atlas account (or local MongoDB)

```bash
# Clone and enter project
cd collaborative-canvas

# Install all dependencies
